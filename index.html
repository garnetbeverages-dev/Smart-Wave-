Backup & Restore
Quick one-off: opens your phone's share sheet to save the file wherever you pick. For a proper repeatable connection to Drive, use the section below instead.
Google Drive Backup
Needs a one-time setup with your own Google account. Unlike Firebase, Google doesn't allow a plain web page silent unattended access — so this connects for the current session and you tap Backup/Restore when you want them, rather than running automatically at midnight.
Not set up
1. Go to console.cloud.google.com and pick the same "smart-wave-own" project Firebase already uses (Firebase projects ARE Google Cloud projects).
2. APIs & Services → Library → search "Google Drive API" → Enable.
3. APIs & Services → OAuth consent screen → set up as External, app name "Purelish", add your own email as a test user. The scope this app uses (drive.file — only files it creates) usually doesn't need Google's full verification.
4. APIs & Services → Credentials → Create Credentials → OAuth client ID → Application type "Web application".
5. Under "Authorized JavaScript origins" add this page's exact origin, e.g. https://garnetbeverages-dev.github.io.
6. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it above.
Automatic Daily Backups
A local snapshot is saved automatically every midnight (and immediately on catch-up if the app was closed at midnight). Last 30 days are kept on this device, and mirrored to cloud history too.
Cloud Backup (Firebase)
Pre-configured and always on — this app syncs to Purelish's dedicated cloud project automatically. Cannot be turned off, to make sure data is never lost.
